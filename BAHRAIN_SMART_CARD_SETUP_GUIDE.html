🇧🇭 Bahrain Smart Card Reader Setup Guide

Complete deployment & 1-click installation manual for any computer (Reception Desk, Doctor Room, or Dental Branch PC).

✓ Supports Old CPR Cards (Front Chip)
✓ Supports New 2025/2026 CPR Cards (Back Chip - V6)
⚡ Local High-Speed Bridge (Port 5050)
✨ Engineered by SaNDS Lab
★ 1-Click Auto Setup
1
Plug in the USB Smart Card Reader

Connect any standard USB Smart Card Reader (ACS ACR38/ACR39, Rocketek, Alcor Micro, Identiv, or generic EMV reader) into an available USB port.

✓ Automatic Driver: Windows 10 & 11 install standard CCID drivers automatically. No manual driver setup is required.
2
Extract Files to Your PC

Extract this package to your local drive (e.g. C:\Al Rabeesh Software\ or D:\Al Rabeesh Software\).

The folder contains the pre-configured BahrainCardBridge\ application engine and the Start_Bahrain_Card_Bridge.bat launcher.

3
1-Click Launch (Start_Bahrain_Card_Bridge.bat)

Right-click Start_Bahrain_Card_Bridge.bat and select "Run as administrator" (or double click to run).

What the script automatically does:
  • Stops and disables any conflicting legacy Windows services.
  • Registers Windows URL ACL permissions for Port 5050.
  • Starts the Al Rabeesh Smart Card Bridge listening on http://localhost:5050/.
4
Verify & Test Card Reading

Insert a Bahrain CPR card into the reader and test via the diagnostics page or the Al Rabeesh Dental Web App:

🔍 Open Hardware Diagnostic (Port 5050) ● Service Health Check
💳 Card Orientation Tip:
  • Old CPR Cards (Chip on front): Insert with gold chip facing UP.
  • New 2025/2026 Smart Cards (Chip on back): Insert with gold chip facing DOWN/TOWARDS CONTACTS so the reader detects the chip.
5
Optional: Start Automatically on PC Boot

To have the reader service start automatically whenever the receptionist or doctor turns on the PC:

  1. Press Win + R, type shell:startup, and press Enter.
  2. Right-click inside the folder → New → Shortcut.
  3. Select Start_Bahrain_Card_Bridge.bat as the target.

🛠️ Quick Troubleshooting

Issue Probable Cause Solution
"No smart card reader detected" USB reader unplugged or Windows service stopped Ensure USB reader is firmly plugged in. Check that Windows Smart Card service (SCardSvr) is running.
"Card removed or cannot read" Card inserted upside down or backwards Verify card chip orientation (Front chip = face up, Back chip = face down). Push card completely into the slot.
"HTTP 503 / Port Conflict" Old service occupying port Simply run Start_Bahrain_Card_Bridge.bat as Administrator to auto-clear conflicts.
